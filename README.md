## AppImage with some googies

Scripts that helps compiling goodies like
 [elinks](https://github.com/rkd77/elinks ),
 [qjs and qjsc](https://github.com/quickjs-ng/quickjs )
 into one AppImage file. It can be used as base for compiling other goodies
 into one

It can be compiled with [chawan](https://git.sr.ht/~bptato/chawan ),
by `main --with-chawan`

For more information run `./$APPIMAGENAME --run h`
